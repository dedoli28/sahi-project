# Veri Seti

Bu klasör, model eğitimi için kullanılacak gerçek ve yapay zeka ile üretilmiş
görsel/video/ses örneklerini içerecektir.

- `raw/` — ham, işlenmemiş veri
- `processed/` — eğitime hazır, işlenmiş veri

Büyük veri dosyaları `.gitignore` ile repodan hariç tutulmuştur; veri setini
ayrı bir depolama (Google Drive, Hugging Face Datasets vb.) üzerinden paylaşmanız
önerilir.
